# Provenance and AI assistance

Work on ExactSplit began on November 3, 2026. Its Fe allocation library, rotation policy integration, runtime tests, reference tooling and documentation were created for this project. The largest-remainder method is a known allocation method; no claim of inventing it is made.

Codex AI development agents assisted with implementation, testing, documentation and review. One agent implemented the Fe core; another mathematical review used separately constructed adversarial cases and exhaustive calculations. The Python reference uses enumeration rather than the core's repeated winner selection. Internal reviews are agent reviews, not a claim that a human personally ran commands or wrote the code manually.

Nerion Dev is the responsible project contact. Before a contest submission, the human maintainer must review and be able to explain the actual project, its limitations and the declared AI assistance. A public repository alone is not a contest registration, acceptance, award or payment.

Pre-existing material consists of Fe's external compiler/standard library and public language documentation used to learn its syntax. The preliminary arithmetic portability probe was separate from this project's implementation. No other contestant's implementation was copied or used as an oracle. No customers, sales, production deployments or performance gains are claimed.

The project is prepared for the [Fe Builders Challenge](https://fe-lang.org/contest/). The contest requires a meaningful Fe contribution, reproducible evidence, an OSI-approved public source license and disclosure of reused work and AI assistance. Registration and final submission are separate from development.
